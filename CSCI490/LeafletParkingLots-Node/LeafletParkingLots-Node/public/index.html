Leaflet Parking Lots

OSM + Draw + Save/Load GeoJSON (Node)
Tip: Set to your campus, then click Go.
How to use
  1. Pan/zoom to your campus.
  2. Use the Draw control on the map (bottom-left) to create polygons for lots.
  3. Click a shape to edit properties: name, capacity (stored server-side in GeoJSON).
  4. Data persists on the server (`data/parking_lots.geojson`).
Selected Feature Properties
Edit properties for the currently selected shape.
