## Notes & Limitations
================================================================================
- On WSL/VMs, many hardware details are virtualized (cache/DIMM/storage firmware).
- For detailed DIMM info, run with sudo and have dmidecode installed: sudo dmidecode -t memory
- For deeper CPU/cache/NUMA topology, install hwloc (lstopo).
- The 'FLOPS' proxy is a quick compute workload; use LINPACK/HPL for rigorous FLOPS.
